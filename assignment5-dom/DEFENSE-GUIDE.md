# Assignment 5: қорғауға дайындық

**Команда:** Apex Motors. **Топ:** SE-2507. **Қатысушылар:** Arsen, Kuttibay, Farabi, Muhammad.

Жоба HTML, CSS және JavaScript арқылы жасалған. Бес бөлек бет: `index.html`, `inventory.html`, `showroom.html`, `inquiry.html`, `about.html`. Навбардағы сілтемелер жеке бетті ашады.

Нақты тапсырмада HTML, CSS және JavaScript-ті бөлу талап етіледі. Барлығын бір HTML файлына жинау талап етілмейді. **OR** баламалардың біреуін таңдау дегенді білдіреді. Біз Read More, thumbnail арқылы негізгі суретті ауыстыру және көпқадамды форма нұсқаларын көрсеттік; күн/түн де, фонды JavaScript арқылы өзгерту де бар.

## Бес-жеті минуттық көрсету реті

1. `index.html` аш. Үлкен сапалы көлік фотосы, Apex Motors стилі және бес бетті көрсет. Collection басқанда адрес `inventory.html` болып өзгереді.
2. Күн/түнді ауыстыр. Фон батырмасын бірнеше рет бас: ол үш дайын түсті қайталамайды, жаңа реңк жасайды. Басқа бетке өт, жаңарт: браузер сақтауына рұқсат болса, баптаулар сақталады.
3. Tab немесе жебе пернесімен навбарға фокус қой. Оңға/төмен келесі, солға/жоғары алдыңғы элементке апарады; шетіне жеткенде айналып өтеді. Қысқа дыбысты көрсет. Enter таңдалған бетті ашады. Форма ішіндегі жебелер енгізуге кедергі жасамайды.
4. `inventory.html` бетінде 17 көлік барын көрсет және категорияларды ауыстыр. Карточкалар мен сан DOM арқылы жаңарады. Екі көлікті сақта, Saved аш, бетті жаңарт. `inventory.html?saved=1` сақталған жинақты бірден ашады.
5. Карточкадан inquiry аш. `inquiry.html` бетінде көлік алдын ала таңдалады. Бос формада Next басып, қате мен фокусты көрсет. Sample ат/email енгіз; Preferences және Review-ге өт. Back мәндерді сақтайды. Confirm жергілікті нәтижені көрсетеді; Reset тазартады.
6. `showroom.html` бетінде thumbnail таңда және Previous/Next батырмаларын бас. Негізгі үлкен сурет, оның alt мәтіні, caption және таңдалған thumbnail күйі JavaScript арқылы өзгеретінін көрсет. Фотолар жобаға қосылған, галерея үшін сыртқы сервис қажет емес.
7. `about.html` бетінде Read More-ды ашып-жап, FAQ және төрт командаластың фотосын көрсет. Телефон енінде мәзірді тексер.

## Негізгі сұрақтар

**DOM деген не?** Браузер HTML-ді объектілер ағашына айналдырады. JavaScript элементті тауып, мәтінін, атрибутын немесе стилін өзгертеді.

**`querySelector` мен `querySelectorAll` айырмасы?** Біріншісі бірінші сәйкес элементті, екіншісі барлық сәйкес элементтердің `NodeList` жинағын береді.

**`textContent` не үшін?** Мәтінді HTML ретінде орындамай көрсетеді. Мысалы, формадағы ат қарапайым мәтін болып шығады.

**`addEventListener` не істейді?** `click`, `keydown`, `change` немесе `submit` болғанда берілген функцияны шақырады.

**Callback деген не?** Басқа функцияға аргумент ретінде берілген функция. Формада келесі қадамды есептейтін функция оны көрсететін callback-ті шақырады. Кодтан callback берілетін және орындалатын жерлерді көрсет.

**Back мәндерді қалай сақтайды?** JavaScript қадамдардың көрінуін өзгертеді, енгізу элементтерін қайта жасамайды.

**Объект әдісі деген не?** Объектінің деректерімен жұмыс істейтін функция. Көлік қасиеттері объектте, әдісі карточкадағы сипаттамаға қолданылады.

**Көлік тізімі неге бір жерде?** Карточкалар мен inquiry таңдауы ортақ массивтен құрылады. Жаңа көлік бір жерде қосылады.

**Higher-order function деген не?** Басқа функцияны қабылдайтын немесе қайтаратын функция. `filter(predicate)` сәйкес объектілердің жаңа массивін береді.

**`switch` не үшін?** Категорияға сәйкес `case` орындалады; `default` жалпы жағдайды өңдейді.

**Saved қалай сақталады?** Көлік ID тізімі JSON арқылы браузерде сақталады. Қайта оқығанда белгілі ID-лер тексеріледі. Сақтау шектелсе, қате бүкіл сайтты тоқтатпауы керек.

**Күн/түн мен фон айырмасы?** Тақырып мәтін мен панельдердің жарықтығын өзгертеді. Фон батырмасы реңкті өзгертеді. Екі тақырып та оқылатын болуы керек.

**Неге жебелер бірден бетті ашпайды?** Тапсырма мәзір фокусын жылжытуды сұрайды. Enter бетті ашады.

**Дыбыс неге қабаттаспайды?** Бір белсенді дыбыс бақыланып, келесісін бастағанда алдыңғысы тоқтайды. Дыбыс пайдаланушы әрекетінен кейін шығады.

**Неге қозғалыс кейде аз?** `prefers-reduced-motion` жүйелік баптауы ескеріледі.

**Inquiry серверге жіберіле ме?** Бұл оқу демонстрациясы: мәндер браузерде тексеріліп, жергілікті нәтиже көрсетіледі. Backend қажет етпейтін multistep баламасы таңдалған.

**Галерея суретті қалай өзгертеді?** Thumbnail батырмасынан сурет жолы алынып, үлкен суреттің `src` және `alt` атрибуттары жаңартылады. Caption және таңдалған элементтің `aria-pressed` күйі де жаңарады. Бұл тапсырмадағы attribute manipulation баламасына сәйкес келеді.

**Неге Hyundai Accent, Audi RS 6 Avant және Audi A5 Sportback деп өзгерді?** Бұрынғы жасанды атаулардың орнына суреттегі көліктердің аттары қойылды. Баға мен жылдар оқу жобасының мысал мәндері, нақты сату ұсынысы емес.
