## Бес минуттық көрсету реті

1. Басты бетті аш. Apex Motors тақырыбы және алдыңғы жобадағы суреттер сақталғанын түсіндір.
2. Collection бөлімінде категорияны өзгерт. Сүзгі мен нәтиже саны бетті қайта жүктемей жаңарады. Баға бойынша сұрыптап, іздеу мен сақталған машиналар сүзгісін бірге тексер.
3. View details арқылы диалогты аш. Thumbnail басқанда үлкен суреттің `src` және `alt` атрибуттары өзгереді. Диалогты Escape арқылы жап.
4. Theme батырмасын бас. JavaScript күйді өзгертеді, CSS түстерді қолданады. Rating батырмаларының таңдалған күйін және Read more мазмұнын көрсет.
5. Мәзірдегі бір сілтемеге Tab арқылы фокус қой. ArrowRight, ArrowLeft, Home және End пернелерін бас. `.focus()` қай элементке өтетінін түсіндір.
6. Booking формасын бос күйінде жалғастырып көр. Қате хабарламалары мен бірінші қате өріске фокус ауысуын көрсет. Барлық өрісті дұрыс толтыр, Back басып ақпараттың сақталғанын көрсет, review жаса, consent таңда, аяқта.
7. Reset/Book again арқылы барлық өрісті, қателерді және қадам күйін тазарт. Бұл нақты бронь жасамайтын жергілікті демонстрация екенін айт.
8. Sound батырмасын бірнеше рет бас. Алдыңғы дыбыс тоқтатылып, жаңасы басталатындықтан дыбыстар қабаттаспайды. FAQ transition мен карточкалардың анимациясын көрсет.
9. Телефон енін немесе responsive режимді көрсет. Қате болмағанын тексерген браузерлік есеп пен PDF-тегі дәлелдерді аш.

## Оқытушы сұрауы мүмкін сұрақтар

**DOM деген не?** Браузер HTML-ді объектілер ағашына айналдырады. JavaScript сол элементтерді таңдап, мәтінін, атрибутын және күйін өзгертеді.

**`querySelector` мен `querySelectorAll` айырмашылығы қандай?** Біріншісі бірінші сәйкес элементті қайтарады, екіншісі сәйкес элементтердің `NodeList` жинағын береді. Бірнеше батырмаға listener қою үшін жинақты `forEach` арқылы өтеміз.

**Неге `textContent` қолданылған?** Мәтін қауіпсіз енгізіледі. Пайдаланушының аты HTML ретінде орындалмайды.

**Callback деген не?** Басқа функцияға аргумент ретінде берілетін функция. Қадамды ауыстыру логикасы callback-ті шақырады, ал callback тиісті қадамды көрсетіп, индикатор мен summary-ді жаңартады.

**Жоғары ретті функция деген не?** Басқа функцияны қабылдайтын немесе қайтаратын функция. `vehicles.filter(predicate)` әр объектіні `predicate` функциясымен тексеріп, жаңа массив жасайды.

**Объект пен массив не үшін керек?** Объект бір машинаның қасиеттерін біріктіреді; массив машиналар жинағын сақтайды. Цикл жинақтан DOM карточкаларын жасайды. Объект әдісі қайталанатын логиканы бір жерге жинайды.

**`switch` қайда қолданылған?** Машиналарды категория бойынша сүзгенде қолданылған. Таңдалған category сәйкес `case` тармағын орындайды, ал `default` жалпы жағдайды өңдейді.

**Неге формада `preventDefault()` бар?** Браузердің стандартты submit әрекетін тоқтатып, ағымдағы бетте валидация және confirmation көрсету үшін. Тапсырмадағы callback баламаларының ішінен multi-step form таңдалды; желілік POST қажет емес.

**Back басқанда деректер неге жоғалмайды?** Қадамдар бір форманың бөліктері. Көрінетін қадам өзгереді, бірақ input элементтері қайта жасалмайды, сондықтан мәндері сақталады.

**Дыбыстың қабаттасуын қалай тоқтаттыңдар?** Жаңа playback алдында алдыңғы playback тоқтатылады немесе бір audio source қайта басталады. Автоматты ойнату жоқ: дыбыс пайдаланушы басқаннан кейін қосылады.

**Анимация неге кейде азаяды?** `prefers-reduced-motion` жүйелік баптауы ескеріледі. Қозғалысты азайтуды таңдаған пайдаланушыға ұзақ transition көрсетілмейді.

**HTML, CSS, JS қалай бөлінген?** HTML құрылымды, CSS сыртқы көріністі, сыртқы JavaScript файлдары мінез-құлықты басқарады. `defer` скриптті HTML талданғаннан кейін іске қосады.

## Өзің орындап жаттығатын шағын өзгерістер

- Массивке жаңа машина қосып, карточка мен vehicle select жаңарғанын тексер.
- Категорияның жаңа мәнін қосып, тиісті `case` тармағын жаз.
- Rating хабарламасын немесе story мәтінін өзгертіп, нәтиже DOM-да жаңарғанын көрсет.
- Формаға жаңа валидация ережесін қосып, қате және дұрыс мәндермен тексер.
- Theme түсін CSS айнымалысында немесе animation уақытын stylesheet ішінде өзгертіп көр.
