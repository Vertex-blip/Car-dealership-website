## Әр адам білетін ортақ жауаптар

1. **JavaScript қалай қосылған?** `index.html` файлында төрт сыртқы JS файл `<script defer>` арқылы қосылған. `defer` HTML талданғаннан кейін кодты орындайды.
2. **Неге форма серверге жіберілмейді?** Бұл тапсырма тек клиент жағындағы валидацияны сұрайды. `event.preventDefault()` стандартты жіберуді тоқтатады. Нақты тіркелгі немесе хабарлама жасалмайды.
3. **FAQ қалай жұмсақ ашылады?** JS `is-open` класын ауыстырады; CSS `grid-template-rows: 0fr` пен `1fr` арасын анимациялайды.
4. **Pop-up жабылуы қалай істейді?** × батырмасы `close()` шақырады; сыртқы аймақтың координаттары тексеріледі; Escape-ті `<dialog>` браузердің өз механизмімен өңдейді.
5. **Сағат неліктен нақты уақытты көрсетеді?** Әр секундта жаңа `Date` алынады, `Intl.DateTimeFormat` оны оқуға ыңғайлы мәтінге айналдырады.
6. **Қолжетімділік не үшін қажет?** Қателер өріспен `aria-describedby` арқылы байланысқан; FAQ `aria-expanded` күйін береді; pop-up жабылғанда фокус оны ашқан батырмаға оралады.
