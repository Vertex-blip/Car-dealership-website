# Assignment 3 — Media Queries + Bootstrap Grid

**Apex Motors · Group SE-2507**<br>
**Team:** Arsen, Kuttibay, Farabi, Muhammad

This folder is a self-contained copy for Assignment 3. The original Assignment 1/2 website at the repository root is not modified by this project. Open `index.html` to start the eight-page demonstration.

## Pages and rubric coverage

| Page | Demonstration | Primary contribution |
|---|---|---|
| `index.html` | Bootstrap 5.3 responsive navbar, collapse toggler, linked assignment overview | Farabi |
| `typography-cards.html` | Mobile/tablet/desktop type sizes and three CSS-media-query cards (no Bootstrap card/grid classes) | Muhammad |
| `grid-spacing.html` | Two `col-lg-6` columns, three `col-lg-4` columns, container and responsive spacing utilities | Muhammad |
| `carousel.html` | Nine local images, nine indicators, captions, previous/next controls | Arsen |
| `bootstrap-cards.html` | Three image/title/description Bootstrap cards in a responsive grid | Arsen |
| `buttons.html` | Primary, secondary, outline, large/small buttons and accessible `.btn-group` | Kuttibay |
| `responsive-form.html` | Responsive labeled fields, `.form-control`, `.input-group`, checks, radios and browser validation | Kuttibay |
| `team-grid.html` | Responsive Bootstrap two-/three-/four-column examples and explicit contribution map | Farabi |

Each HTML page links to all eight pages and includes the full team list in its footer. Bootstrap CSS and the JavaScript bundle are loaded from jsDelivr; carousel and navbar interaction therefore require an internet connection. Car photographs are local under `images/`.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server and visit `/assignment3-bootstrap/`. The inquiry form demonstrates client-side required-field and email validation only; it deliberately does not send or store personal data.
