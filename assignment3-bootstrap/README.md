# Apex Motors — Assignment 3

**Group SE-2507** · Arsen · Kuttibay · Farabi · Muhammad

This is a self-contained Assignment 3 project. It is intentionally separate from the Assignment 1/2 site at the repository root. Open `index.html` to explore the site.

## Pages and rubric coverage

| Page | Demonstration | Contribution |
|---|---|---|
| `index.html` | Editorial home, supplied logo, Bootstrap 5.3.3 collapsing navbar, links to every task page | Farabi |
| `typography-cards.html` | Responsive typography at phone/tablet/desktop breakpoints; three cards laid out only with CSS media queries | Muhammad |
| `grid-spacing.html` | Two-column `col-lg-6` and three-column `col-lg-4` Bootstrap sections; responsive spacing utilities | Muhammad |
| `carousel.html` | Nine unique local vehicle photographs, captions, indicators, keyboard support, and previous/next controls | Arsen |
| `bootstrap-cards.html` | Three image/title/description/action cards in a responsive Bootstrap grid | Arsen |
| `buttons.html` | Primary, secondary, outline, large/small Bootstrap buttons and an accessible button group that stacks on tablet and phone widths | Kuttibay |
| `responsive-form.html` | Responsive labeled form, `form-control`, `input-group`, select, radio, checkbox, and client-side feedback | Kuttibay |
| `team-grid.html` | Four supplied member portraits, contribution map, and links to each member's two pages | Farabi |

Every site page has the Apex Motors logo in its responsive navbar and the complete team list in its footer. The shared `styles.css` customizes Bootstrap to match the dealership's charcoal, cream, and copper identity without changing the root site styles. The CSS-only card exercise uses no Bootstrap grid or card classes for its layout.

## Local run

Open `index.html` directly or serve the repository root with a static file server and visit `/assignment3-bootstrap/`. Bootstrap CSS and its JavaScript bundle are loaded from jsDelivr. All car, team, and brand images are local. The form validates in the browser only; it does not send or store personal data.
