# Assignment 6 - қорғауға дайындық

**Apex Motors · SE-2507 · Arsen, Kuttibay, Farabi, Muhammad**

Жоба Assignment 5-тегі автосалон сайтын жалғастырады. HTML, CSS және JavaScript бөлек сақталған. jQuery DOM-мен, оқиғалармен және анимациялармен жұмысты жеңілдетеді.

## Көрсету реті

1. **Task 0.** Браузер консольін ашыңыз: `jQuery is ready!` шығады. HTML-дің `<head>` бөлімінде jQuery 4 CDN-нен қосылған. `script.js` ішіндегі `$(document).ready()` DOM дайын болғанда орындалады. CDN ашылмаса, жергілікті көшірме қолданылады.
2. **Task 1.** Collection бетінде `Porsche` деп теріңіз. Карточкалар бірден сүзгіленеді; қайта жүктеу қажет емес. Іздеуді тазаласаңыз, толық жинақ қайтады. Категория, баға бойынша сұрыптау және Saved сүзгісі де жұмыс істейді.
3. **Task 2.** `Mer` деп теріп, ұсыныстарды көрсетіңіз. Төмен/жоғары бағыттауыш, Enter және Escape пернелерін қолданыңыз. Ұсынысты тінтуірмен де таңдауға болады.
4. **Task 3.** About бетіндегі FAQ іздеуіне `car` енгізіңіз. Сұрақтар мен жауаптардағы барлық сәйкес сөздер боялады. Іздеуді тазалағанда бастапқы мәтін қалпына келеді. Пайдаланушы мәтіні HTML ретінде орындалмайды.
5. **Task 4.** Ұзын бетті жоғарыдан төменге айналдырыңыз. Жоғарғы градиент жолақ оқылған бөлікті көрсетеді. Формула: `scrollTop / (documentHeight - viewportHeight) * 100`; қысқа бетте нөлге бөлуге жол берілмейді.
6. **Task 5.** Home статистикасына өтіңіз. Сандар біртіндеп соңғы мәніне жетеді. Анимация көрінгенде басталады; reduced motion қосылса, соңғы мән бірден көрсетіледі.
7. **Task 6.** Inquiry-ді бос күйде жіберіп, валидацияны көрсетіңіз. Кейін үлгі деректерді толтырып, үш қадамнан өтіңіз. Submit кезінде spinner және `Please wait…` көрінеді, батырма уақытша өшеді. Қайталанған жіберілім еленбейді. Reset күтіп тұрған әрекетті тоқтатады.
8. **Task 7.** Көлікті сақтаңыз: қысқа хабарлама пайда болып, кейін өшеді. Бұл әрекет орындалғанын көрсетеді.
9. **Task 8.** Дайын inquiry мәтінінің жанындағы Copy батырмасын басыңыз. Мәтінді басқа өріске қойып, нақты көшірілгенін тексеріңіз. Сәтті болса, белгі checkmark-қа ауысып, tooltip шығады.
10. **Task 9.** Collection бетін жаңадан ашып, DevTools Network бөліміндегі суреттерді қараңыз. Төмендегі суреттер экранға келгенге дейін олардың нақты URL-і `data-src` ішінде болады. Айналдырғанда `src` тағайындалып, сурет жүктеледі.
11. Жарияланған URL-ді және PDF есептегі скриншоттарды көрсетіңіз.

## Түсіндіре білу керек

- `.on()` оқиға өңдеушісін тіркейді; `input` оқиғасы теруді де, paste әрекетін де қамтиды.
- jQuery `.filter()` элементтер жиынын шарт бойынша азайтады; `.text()` мәтінді қауіпсіз енгізеді.
- `.attr()` HTML атрибутын, `.prop()` `disabled` сияқты DOM күйін өзгертеді.
- `.animate()` сандық мәнді уақыт бойынша өзгертеді; `.fadeOut()` хабарламаны біртіндеп өшіреді.
- Clipboard API нәтижесі асинхронды. Тек көшірілгені расталғаннан кейін сәттілік көрсетіледі.
- Lazy loading нақты суреттің сұрауын кейінге қалдырады; жай ғана CSS-пен жасыру жүктеуді тоқтатпайды.
- Submit үшін `pending` күйі қайталанған әрекетті, ал таймерді тазарту кешігіп шығатын ескі нәтижені болдырмайды.
- FAQ highlighting алдында бұрынғы `mark` элементтері алынады; іздеу мәтіні орындауға болатын HTML ретінде енгізілмейді.
- FAQ сұрағының бүкіл мәтіні `.faq-question` ішінде, ал ашу белгісі бөлек `.faq-icon` ішінде тұрады. Сондықтан `mark` элементтері flex аралықтарына бөлінбей, сөздің ішінде дұрыс қалады.

## Шектеулер және reflection

Бұл оқу жобасы: inquiry серверге жіберілмейді және нақты бронь жасалмайды. Бағалар үлгі ретінде берілген. Негізгі қиындықтар - іздеу мен басқа сүзгілердің бірге жұмыс істеуі, autocomplete пернетақтасы, қайталанған submit, қауіпсіз highlighting және CDN қолжетімсіз болғандағы жұмыс. Шешімдер: бірізді сүзгі күйі, қолжетімді listbox, pending қорғанысы, мәтін түйіндерімен жұмыс және жергілікті jQuery fallback.

Әр қатысушы PDF пен ZIP-ті LMS-ке өзі тапсырады. Қорғау 40% болғандықтан, тек өзінің бөлігін емес, барлық тапсырманы түсіндіруге дайын болуы керек.
